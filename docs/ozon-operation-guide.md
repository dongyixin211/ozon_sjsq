# Ozon 工作台操作文档

## 1. 进入店铺工作台

1. 打开应用后进入“上架运维”。
2. 在“店铺管理”里选择要操作的店铺。
3. 点击“功能中心”进入该店铺的工作台。
4. 进入后先看“任务总览”，确认当前店铺、API Key、模板、仓库缓存和订单输出目录状态。

## 2. 发布新品

适用场景：把 Excel 中的新商品发布到 Ozon。

操作步骤：

1. 进入“发布新品”。
2. 选择 3:4 图片目录。
3. 选择上传 Excel。
4. 设置最大条目数量。
5. 如果商品需要视频，填写视频链接，每行一个。
6. 在“商品模板”中选择已保存模板，或输入线上模板货号后点击“读取线上模板”。
7. 点击“预检查”，确认没有阻断问题。
8. 点击“提交上架任务”。
9. 到“任务记录”查看进度、日志和结果。

## 3. 更新商品

适用场景：按货号更新已上架商品的信息。

操作步骤：

1. 进入“更新商品”。
2. 选择 3:4 图片目录和 Excel。
3. 勾选本次要更新的字段：标题、简介、图片、视频、JSON 富内容。
4. 如需沿用模板结构，选择或读取商品模板。
5. 点击“预检查”。
6. 点击“提交更新任务”。
7. 到“任务记录”查看任务结果。

## 4. 下载订单文件

适用场景：按订单号或货件编号下载发货所需文件。

操作步骤：

1. 进入“下载订单文件”。
2. 在“订单输入”中填写订单/货件编号。可以一行一个，也可以用空格、逗号分隔。
3. 在“保存位置”选择输出目录。系统会自动记住上一次选择的目录。
4. 在“后台授权”中选择 Ozon HAR 文件，或粘贴 Ozon 后台 Cookie。Cookie 会自动保存。
5. 如果需要同步下载货号素材，保持“下载货号素材”开启，填写并保存百度网盘 Cookie，同时确认搜索目录。
6. 点击“开始下载”。
7. 点击“查看任务”进入任务记录，查看日志和下载结果。

下载结果：

- 每个订单/货件编号会创建独立文件夹。
- 文件夹中包含 Ozon 标签、条码 PDF、拣货单 PDF。
- 如开启货号素材下载，会同时保存匹配到的素材文件。
- 订单下载不会额外保存调试用 JSON 文件。

## 5. 库存、价格和活动

适用场景：查询商品后批量调整库存、价格、条码或活动。

操作步骤：

1. 进入“库存价格活动”，默认停留在“商品列表”模式。
2. 在“商品列表”里点击“加载分类”，再用类目搜索定位目标分类。
3. 点击“查询商品”加载商品列表；也可以直接点击“拉取零库存”或“拉取无条码”。
4. 如需补库存，先在“处理商品”中点击“查询仓库”，再选择仓库和库存数量。
5. 如需改价，填写新售价、可选划线价和备用币种。
6. 如果要处理所选类目下全部商品，在“所选类目全部商品”中点击“更新类目库存”“更新类目价格”或“同时更新”。
7. 如果只处理当前查询出来的列表，在“当前列表更新库存”或“当前列表更新价格”中操作。
8. 如需活动申报，先切换到“活动申报”模式。
9. 如需新增活动商品，点击“查询活动”，选择活动后点击“查询可参加商品”。
10. 在“可参加商品”表中勾选商品，确认统一活动价和活动库存，然后点击“新增参加活动”。
11. 如需删除活动商品，点击“查询已参加商品”，在“已参加商品”表中勾选商品，然后点击“删除参加活动”。
12. 如需清空当前活动下全部商品，确认活动无误后点击“删除当前活动所有商品”，并在弹窗中确认。

注意：

- 普通商品表的勾选只用于库存、价格、条码等商品列表操作，不再直接用于新增活动。
- “所选类目全部商品”会扫描该类目下全部商品，不受“返回数量上限”影响；操作前请确认类目和类型 ID。
- 活动新增必须从“可参加商品”列表中选择商品，因为 Ozon 只允许候选商品参加对应活动。
- “删除当前活动所有商品”会分页扫描并删除该活动下全部已参加商品，不只删除当前页。

## 6. 上架后自动处理

1. 进入“发布新品”，打开“上架后自动处理”。
2. 刷新并选择库存仓库，填写库存数量。
3. 刷新并选择促销活动；活动价可留空，由程序优先使用活动候选商品返回的建议价。
4. 提交上架任务。商品获得 Ozon 商品 ID 后，程序会自动生成条码、补库存并加入活动。
5. 某一项自动处理失败不会中断后续商品，具体原因可在任务日志和结果表中查看。

## 7. 浏览量与合并商品卡

1. 进入“浏览量与合并”，选择统计日期和最低详情页浏览量。
2. 点击“查询浏览量”，列表会按详情页浏览量从高到低排列。
3. 勾选需要合并的商品。程序只会把相同类目、相同类型的商品放在同一组。
4. 点击“合并所选商品”，检查预计分组数后再次确认。
5. 每组最多 20 个商品；不足 2 个、缺少类目/类型或缺少型号属性的商品会自动跳过。

## 8. 接口诊断

适用场景：检查店铺配置或 Ozon 接口连通性。

操作步骤：

1. 进入“接口诊断”。
2. 点击“测试 Ozon”查看连接测试结果。
3. 如接口失败，先检查店铺设置中的 Client ID 和 API Key。

## 9. 日常建议

- 新店铺第一次使用前，先进入“库存价格活动”查询仓库，再到“接口诊断”测试连接。
- 发布和更新商品前，先维护好商品模板，减少类目和属性缺失。
- 订单下载页会记住订单号、Cookie 和输出目录；如果不想复用旧订单号，开始前手动清空订单输入框。
- 所有长任务都在“任务记录”中看进度和日志。
