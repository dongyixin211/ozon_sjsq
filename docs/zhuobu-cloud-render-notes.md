# 桌布云端套图优化记录

更新时间：2026-07-04

## 本次目标

桌布样机继续使用 Node.js + sharp 云端渲染，不调用 Photoshop Worker。目标是让云端套图尽量接近 Photoshop 成品，并保留可量化的 PS 对比诊断。

## 已完成改动

- 从 Photoshop 导出的智能对象描述中注入桌布透视网格，19 个替换层均带 `perspectiveMesh`。
- 修复第 5 场景透视点存在额外整屏 Y 偏移的问题，避免桌面区域大面积未铺图。
- 透视替换层现在支持 `opacity`，后续模板参数调整会真实生效。
- 模板级 `linearLightStrength` 现在会参与线性光合成。
- 桌布模板设置 `linearLightStrength: 0.25`，降低图案过硬、浮在桌面上的感觉。
- 对比脚本使用 Unicode 路径，支持中文目录，输出单图和批量相似度。

## 未达标原因

当前云端算法已经能复现 PSD 的 16 点透视网格，但仍不能完全复刻 Photoshop 的智能对象渲染、透视变形抗锯齿、图层颜色管理、滤镜混合和布料褶皱细节。最差样本 `TM20251026002593` 的高对比黑白红曲线会放大这些差异，导致场景 1、2、7 仍低于 92%。

继续只靠参数搜索提升有限。已验证以下参数对重点场景影响很小：

- 采样像素偏移
- 透视插值算法
- 源图预处理尺寸和 fit 策略
- 替换层边缘羽化

## 后续建议

短期继续使用当前云端算法作为正式功能，优点是速度快、成本低、无需 Windows Photoshop 服务器。

如果商业版需要稳定达到 Photoshop 级效果，建议新增“高精度 PS 渲染队列”：云端负责排队和结果管理，本地或 Windows Worker 调用真实 Photoshop 脚本生成最终套图。这样可以把云端快速预览和高精度出图分成两个会员能力，避免为了极少数复杂样机过度改造通用渲染器。
