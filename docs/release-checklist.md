# 发布检查清单

## 网页、服务端和客户端同步规则

- 只修改服务端：发布服务端，并验证健康接口。
- 只修改网页版：发布网页版，并验证最新 `index.web-*.js` 资源。
- **只要本次改动涉及 `src/`、`src-tauri/`、桌面端前端页面、Rust 调度逻辑或客户端 API 调用，正式环境发布时必须同步构建并发布 Windows 客户端安装包和 updater 清单。**
- 发布客户端后，必须验证客户端版本、安装包下载地址和 updater 清单中的版本一致。
- 不得只发布网页版后声称桌面客户端已更新。

## 自动上架改动

自动上架同时涉及网页版配置页、云端调度和客户端本地执行器。修改其中任一部分，都要明确记录本次发布是否包含：

1. 云端服务端；
2. 网页版工作台；
3. Windows 客户端安装包；
4. updater 更新清单。
