# Ozon SJSQ 使用手册

## 1. 软件用途

Ozon SJSQ 是一个本地桌面工作台，用于集中处理 Ozon 店铺的素材生成、批量上架、已上架商品更新、库存价格维护、促销活动申报、订单查询下载和任务记录查看。

它适合以下场景：

- 批量把 Excel 和商品图片发布到 Ozon。
- 按货号更新线上商品的标题、简介、图片、视频和富内容。
- 批量查询商品、补库存、改价格、生成条码。
- 查询促销活动，并新增或删除活动商品。
- 下载 Ozon 面单、条码、拣货单和可选的货号素材。
- 生成商品 3:4 图片、水印图、AI 商品图和标题文案。
- 查看商品浏览量，并将同类目商品合并为商品卡。

重要提醒：

- 这是本地软件，店铺配置、任务记录和模板保存在本机。
- Ozon Api-Key、OSS Secret、AI Key 等敏感信息通过系统密钥库保存。
- 批量库存、价格、活动删除等操作会影响线上商品，执行前务必确认店铺、类目、商品和活动。

## 2. 首次使用流程

首次使用建议按下面顺序配置。

1. 打开“设置”。
2. 在“店铺与 Ozon”中保存店铺名称、Client-Id 和 Api-Key。
3. 如需批量上架图片，进入“OSS 上传”，填写 OSS 配置并测试上传。
4. 如需 AI 图片或文案，进入“AI Provider”，填写接口、模型和 API Key。
5. 进入“默认目录”，设置源目录、输出目录、水印图片、上架 Excel 模板等常用路径。
6. 打开“上架运维”，选择店铺并进入“功能中心”。
7. 在“库存价格活动”中点击“查询仓库”，确认仓库能正常返回。
8. 在“接口诊断”中点击“测试 Ozon”，确认 Ozon API 连通。

如果只是查询订单或下载订单文件，也需要先保存对应店铺的 Client-Id、Api-Key 和 Ozon 后台 Cookie。

## 3. 页面导航

软件左侧是主导航。

| 页面 | 用途 |
|---|---|
| 首页 | 查看配置状态、今日订单概览和最近任务。 |
| 素材生成 | 转 3:4 图片、加水印、生成 AI 图片、生成标题、图片重命名。 |
| 上架运维 | 店铺级功能中心，包含发布新品、更新商品、订单文件下载、跟卖同步、库存价格活动、浏览量与合并、接口诊断。 |
| 订单查询 | 跨店铺查询订单、统计销售额、批量下载订单文件。 |
| 任务记录 | 查看任务进度、日志、结果文件和失败原因。 |
| 设置 | 配置店铺、OSS、AI Provider 和默认目录。 |

右上角“刷新”用于重新读取本地状态。页面顶部会显示当前运行中任务数量。

## 4. 设置

### 4.1 店铺与 Ozon

入口：设置 → 店铺与 Ozon。

需要填写：

- 店铺名称：本地识别用名称。
- Client-Id：Ozon Seller API 的 Client-Id。
- Api-Key：Ozon Seller API 的 Api-Key。
- 店铺类型：主店或跟卖店铺。
- 跟卖主店：仅跟卖店铺需要选择。
- 跟卖唯一仓库 ID：跟卖店铺有多个仓库时建议填写。
- 店铺水印图片：该店铺专用水印。
- OSS AccessKeyId：图片上传用。

保存后，在“已保存店铺”表格中可以：

- 点击“编辑”回填店铺配置。
- 点击“测试”验证 Ozon 连接。
- 点击“删除”移除店铺配置。

### 4.2 OSS 上传

入口：设置 → OSS 上传。

OSS 用于批量上架时上传商品图片。需要填写：

- OSS AccessKeyId
- OSS Secret
- OSS Bucket
- OSS Endpoint
- OSS Public Domain

保存店铺后，可以在下方店铺列表中点击“测试上传”。测试成功会返回一个可访问的 OSS URL。

### 4.3 AI Provider

入口：设置 → AI Provider。

用于素材页的 AI 图片生成和标题文案生成。需要配置：

- 图片 Provider
- 文案 Provider
- 图片接口
- 文案接口
- 图片模型
- 文案模型
- 图片质量
- 并发数
- 最大文件夹数
- 是否转换原图
- 是否生成文案
- 是否导出 Excel

下方“AI Provider 密钥”中填写图片 API Key 和文案 API Key。若文案 Provider 使用 Ollama，则文案 Key 可不填。

可点击：

- “使用 Pixel 标题”：快速切换文案 Provider 到 Pixel。
- “使用 Ollama 标题”：快速切换文案 Provider 到本地 Ollama。
- “测试文案”：检查文案接口和 Key。
- “测试图片”：检查图片接口和 Key。

### 4.4 默认目录

入口：设置 → 默认目录。

建议配置：

- 默认源目录：原始图片或 SKU 文件夹根目录。
- 默认输出目录：生成结果保存目录。
- 水印图片：默认水印。
- 文案输出目录：AI 标题和文案输出目录。
- 上架 Excel 模板：批量上架默认 Excel。
- 上架最大条目：批量上架默认处理数量。
- 更新最大并发：已上架更新任务的并发数。

这些设置会被素材生成、上架运维和订单下载等页面复用。

## 5. 首页

首页用于快速检查状态。

重点看四类信息：

- 店铺配置：是否已有启用店铺。
- AI 密钥：是否已保存 AI Key。
- 默认目录：是否设置常用目录。
- 最近任务：是否有正在运行或刚完成的任务。

首页的“主流程”会根据配置状态提示下一步操作，例如先配置目录、先配置店铺或进入对应功能。

## 6. 素材生成

### 6.1 转 3:4 + 水印

适用场景：把原图批量转为 3:4 商品图，并叠加水印。

操作步骤：

1. 进入“素材生成”。
2. 在“转 3:4 + 水印”中选择源目录。
3. 选择输出目录。
4. 如需水印，选择水印图片。
5. 设置数量上限；填 0 表示不限制。
6. 点击“预检查”确认路径和配置。
7. 点击“开始转换”。
8. 到“任务记录”查看进度和结果。

### 6.2 GPT 图片生成

适用场景：按 SKU 文件夹生成 AI 商品图。

操作步骤：

1. 选择上传图片目录。
2. 确认 AI 接口和 AI 模型。
3. 填写图片 API Key，并点击“保存 API Key”。
4. 如需更新模型列表，点击“刷新模型”。
5. 设置数量上限。
6. 修改或确认图片 Prompt。
7. 点击“预检查”。
8. 点击“开始生成”。

规则说明：

- 每个 SKU 文件夹默认只取第一张原图作为参考。
- 图片生成失败时会在任务日志中记录原因。

### 6.3 AI 生成标题

适用场景：读取 SKU 图片信息后，批量生成 Ozon 商品标题。

操作步骤：

1. 选择源目录。
2. 选择标题输出目录。
3. 确认 AI 接口和模型。
4. 填写文案 API Key；如果使用 Ollama 可不填。
5. 设置数量上限。
6. 修改或确认标题 Prompt。
7. 点击“预检查”。
8. 点击“开始生成”。

### 6.4 图片重命名

适用场景：按文件名排序复制图片，并生成统一序号文件名。

操作步骤：

1. 选择原素材文件夹。
2. 选择生成后存放目录。
3. 填写前缀，例如 `SKU-`。
4. 检查命名示例。
5. 点击“开始重命名”。

生成文件类似：`SKU-001.jpg`、`SKU-002.jpg`。

## 7. 上架运维

进入“上架运维”后，先在“店铺管理”中选择店铺，点击“功能中心”。进入后默认看到“任务总览”。

### 7.1 任务总览

任务总览用于确认当前店铺状态：

- 当前店铺是否启用。
- API Key 是否已保存。
- 商品模板是否已选择。
- 仓库缓存数量。
- 订单输出目录。

可以从“按目标开始”进入发布新品、更新商品、下载订单文件、跟卖同步、库存价格活动、浏览量与合并、接口诊断等功能。

### 7.2 发布新品

适用场景：把 Excel 中的新商品批量发布到 Ozon。

操作步骤：

1. 进入“发布新品”。
2. 在“批量上架”中选择 3:4 图片目录。
3. 选择上传 Excel。
4. 设置最大条目数量。
5. 如商品需要视频，填写视频链接，每行一个。
6. 在“商品模板”中选择已保存模板，或输入线上模板货号后点击“读取线上模板”。
7. 点击“预检查”。
8. 确认没有阻断问题后，点击“提交上架任务”。
9. 到“任务记录”查看进度、日志和结果 Excel。

发布新品前建议确认：

- Excel 中有货号、标题、简介和 JSON 富文本内容。
- 图片目录中存在与货号匹配的 SKU 文件夹。
- OSS 配置可用。
- 商品模板包含正确类目、类型、属性和尺寸结构。

### 7.3 上架后自动处理

入口：发布新品 → 上架后自动处理。

适用场景：商品上架成功并获得 Ozon 商品 ID 后，自动生成条码、补库存并加入促销活动。

操作步骤：

1. 勾选“启用三项自动处理”。
2. 点击“查询仓库”，选择库存仓库。
3. 填写自动库存数量。
4. 点击“刷新活动”，选择促销活动。
5. 填写统一活动价；可留空，程序会优先使用活动候选商品返回的建议价。
6. 填写活动库存。
7. 提交上架任务。

注意：

- 某个商品的自动处理失败，不会中断后续商品上架。
- 失败原因会写入任务日志和结果表。

### 7.4 商品模板

商品模板决定批量上架或更新时使用的类目、类型、属性结构。

常用操作：

- 读取线上模板：输入线上模板货号后读取商品结构。
- 保存模板：把当前模板保存到本地。
- 删除模板：删除当前选中的本地模板。
- 应用粘贴 JSON：把手动粘贴的 JSON 应用为模板。

建议：

- 新类目第一次上架前，先用线上已成功商品读取模板。
- 不同类目、不同类型不要混用模板。

### 7.5 更新商品

适用场景：按货号更新已上架商品。

操作步骤：

1. 进入“更新商品”。
2. 选择 3:4 图片目录。
3. 选择 Excel。
4. 设置最大条目数量。
5. 勾选本次要更新的字段：标题、简介、图片、视频、JSON 富内容。
6. 如需沿用模板结构，选择或读取商品模板。
7. 点击“预检查”。
8. 点击“提交更新任务”。
9. 到“任务记录”查看结果。

注意：

- 未勾选的字段不会主动更新。
- 更新图片时会重新上传 OSS。
- 不更新图片时会保留线上图片 URL。

### 7.6 下载订单文件

入口：上架运维 → 下载订单文件。

适用场景：按订单号或货件编号下载面单、条码、拣货单和可选货号素材。

操作步骤：

1. 在“订单输入”中填写订单号或货件编号。
2. 可一行一个，也可以用空格、逗号分隔。
3. 在“保存位置”选择输出目录。
4. 在“后台授权”中选择 Ozon HAR 文件，或粘贴 Ozon 后台 Cookie。
5. 点击“保存 Cookie”保存当前店铺后台 Cookie。
6. 如需下载货号素材，开启“下载货号素材”，并填写百度网盘 Cookie 和搜索目录。
7. 点击“开始下载”。
8. 点击“查看任务”进入任务记录。

下载结果：

- 每个订单或货件编号会创建独立文件夹。
- 文件夹中包含 Ozon 标签、条码 PDF、拣货单 PDF。
- 开启货号素材后，会同步保存匹配到的素材文件。

### 7.7 跟卖同步

适用场景：把主店商品补齐到跟卖店铺，并按设置倍率计算售价。

使用前准备：

1. 在“设置 → 店铺与 Ozon”中配置主店。
2. 配置跟卖店铺，并设置“店铺类型”为“跟卖店铺”。
3. 为跟卖店铺选择“跟卖主店”。
4. 如果跟卖店铺有多个仓库，填写“跟卖唯一仓库 ID”。

手动同步：

1. 进入“跟卖同步”。
2. 确认主店和跟卖店铺列表。
3. 设置价格倍率。
4. 点击“开始同步”。
5. 到“任务记录”查看每个商品处理结果。

自动化：

1. 在“跟卖自动化”中设置自动同步、自动补库存、自动生成条码、自动添加活动等选项。
2. 设置执行间隔、最大跟卖数量、库存数量、活动和活动价。
3. 点击“启动自动化”。
4. 如需停止，到“任务记录”中取消对应运行中任务。

### 7.8 库存价格活动

适用场景：查询商品后批量调整库存、价格、条码或活动。

商品列表模式：

1. 进入“库存价格活动”，默认停留在“商品列表”。
2. 点击“加载分类”。
3. 输入类目关键词，选择目标分类。
4. 设置返回数量上限。
5. 点击“查询商品”加载商品列表。
6. 也可以直接点击“拉取零库存”或“拉取无条码”。
7. 在“处理商品”中点击“查询仓库”。
8. 选择补库存仓库，填写补库存数量。
9. 如需改价，填写新售价、可选划线价和备用币种。
10. 如需处理所选类目下全部商品，点击“更新类目库存”“更新类目价格”或“同时更新”。
11. 如只处理当前列表勾选商品，在商品列表下方点击“更新库存”“更新价格”或“生成条码”。
12. 操作提交后，“处理商品”标题下方会显示“提交中”“操作成功”或“操作失败”，并给出本次处理数量、仓库、更新后的库存或价格。

注意：

- “所选类目全部商品”会扫描该类目下全部商品，不受返回数量上限影响。
- 改价前确认币种；商品缺少原币种时需要填写备用币种。
- 库存和价格操作会直接提交到 Ozon，请先确认店铺、仓库和类目。

活动申报模式：

1. 切换到“活动申报”。
2. 点击“查询活动”。
3. 选择活动。
4. 点击“查询可参加商品”查看可加入活动的商品。
5. 在“可参加商品”表中勾选商品。
6. 填写统一活动价和活动库存。
7. 点击“新增参加活动”。
8. 如需删除活动商品，点击“查询已参加商品”，勾选后点击“删除参加活动”。
9. 如需清空当前活动，点击“删除当前活动所有商品”，并按页面提示再次确认。

注意：

- 普通商品表的勾选不用于新增活动。
- 新增活动商品必须从“可参加商品”列表中选择。
- “删除当前活动所有商品”会分页扫描并删除该活动下全部已参加商品，不只删除当前页。

### 7.9 浏览量与合并商品卡

适用场景：按商品详情页浏览量查看商品，并将同类目商品合并为商品卡。

操作步骤：

1. 进入“浏览量与合并”。
2. 选择统计日期。
3. 设置最低详情页浏览量。
4. 点击“查询浏览量”。
5. 勾选需要合并的商品。
6. 点击“合并所选商品”。
7. 页面会先进入确认状态，再次点击后执行合并。

规则说明：

- 只处理勾选商品。
- 严格按“类目 + 类型”分组。
- 每组最多 20 个商品。
- 不足 2 个、缺少类目/类型或缺少型号属性的商品会跳过。
- 合并只处理型号/合并属性，不改标题、图片、价格和库存。

### 7.10 接口诊断

适用场景：检查 Ozon API 是否能连通。

操作步骤：

1. 进入“接口诊断”。
2. 点击“测试 Ozon”。
3. 查看接口返回或错误信息。

若失败，优先检查：

- 店铺 Client-Id 是否正确。
- Api-Key 是否正确且未过期。
- 店铺是否启用。
- 当前网络是否能访问 Ozon Seller API。

仓库查询已移动到“库存价格活动 → 处理商品”。

## 8. 订单查询

入口：左侧导航 → 订单查询。

### 8.1 查询所有店铺订单

适用场景：跨店铺查询订单数量、销售额和订单明细。

操作步骤：

1. 选择开始日期和结束日期。
2. 选择订单状态，或保留“全部状态”。
3. 设置每店最多返回数量。
4. 勾选要查询的店铺。
5. 点击“查询订单”。
6. 在订单列表中查看货件编号、订单号、状态、商品、销售额和处理时间。

页面会汇总：

- 查询订单数量。
- 查询销售额。
- 已勾选订单数量和金额。
- 已保存 Cookie 的店铺数量。
- 下载目录。

### 8.2 下载勾选订单

操作步骤：

1. 查询订单后，在订单列表勾选需要下载的订单。
2. 确认“下载设置”中已保存对应店铺的 Ozon 后台 Cookie。
3. 确认输出目录。
4. 点击“下载勾选”。
5. 到“任务记录”查看下载进度。

### 8.3 下载设置

需要配置：

- 保存 Cookie 到店铺：选择 Cookie 所属店铺。
- 输出目录：订单文件保存目录。
- Ozon 后台 Cookie：可粘贴 Cookie、`Cookie: ...` 或 Copy as cURL 内容。
- 百度网盘 Cookie：下载货号素材时需要。
- 网盘搜索目录：默认可填 `/`。
- 下载货号素材：是否同步下载素材。
- 递归搜索网盘子目录：是否递归搜索。

注意：Ozon 后台 Cookie 按店铺分别保存，不同店铺不会共用。

### 8.4 手动下载订单文件

适用场景：已有订单号或货件编号，不需要先查询列表。

操作步骤：

1. 在“手动下载订单文件”中选择店铺。
2. 输入订单号或货件编号。
3. 可一行一个，也可以用逗号或空格分隔。
4. 点击“下载输入编号”。

## 9. 任务记录

所有长任务都会进入“任务记录”。

可以查看：

- 任务名称和类型。
- 当前状态。
- 进度条。
- 成功和失败数量。
- 输入、输出或结果路径。
- 更新时间。
- 运行日志。

常用操作：

- 日志：查看任务执行过程。
- 结果：打开结果文件或结果目录。
- 失败原因：查看失败任务的错误日志。
- 取消：取消运行中或排队中的任务。
- 刷新：重新读取最新任务状态。

日志区支持分页，可以选择每页 10、20、50 或 100 条。

## 10. 场景图合成

部分版本会提供“本地场景图合成”入口。若当前侧边栏没有该入口，说明该版本暂未开放到主导航。

适用场景：基于模板布局，将商品原图合成为电商场景展示图。

操作步骤：

1. 选择源目录。
2. 选择输出目录。
3. 选择模板目录。
4. 可选：选择单张图片。
5. 选择比例：1:1、3:4、4:3 或 16:9。
6. 可选：填写尺寸标注。
7. 设置数量上限；0 表示不限制。
8. 选择场景模板，例如平铺全幅、头巾侧戴、头巾后戴、折叠系结、尺码图。
9. 点击“开始生成”。

模板目录支持按场景 ID 放置底图，例如 `flat_full.jpg`、`flat_full.png` 或 `flat_full/base.jpg`。

## 12. 常见问题

### 12.1 测试 Ozon 失败

优先检查：

1. Client-Id 是否复制完整。
2. Api-Key 是否复制完整。
3. 店铺是否启用。
4. Ozon 后台 API Key 是否被删除或过期。
5. 当前网络是否能访问 `https://api-seller.ozon.ru`。

### 12.2 批量上架找不到图片

检查：

1. Excel 货号是否与图片文件夹名称一致。
2. 图片目录是否选择到 SKU 文件夹的上一级。
3. 图片格式是否为常见格式。
4. 文件或文件夹名是否包含多余空格。

### 12.3 OSS 上传失败

检查：

1. OSS AccessKeyId 和 Secret 是否正确。
2. Bucket 是否存在。
3. Endpoint 是否与 Bucket 所在区域一致。
4. Public Domain 是否能公开访问图片。
5. 当前网络是否能访问 OSS。

### 12.4 库存更新提示未选择仓库

进入“库存价格活动 → 处理商品”，先点击“查询仓库”，再在“补库存仓库”中选择仓库。

### 12.5 改价提示缺少币种

如果商品没有返回原币种，需要填写“备用币种”，例如 `RUB`。建议先按分类重新查询商品，尽量使用商品原币种。

### 12.6 活动商品新增失败

常见原因：

- 没有先查询可参加商品。
- 商品不在该活动候选列表中。
- 活动价为空或不符合活动规则。
- 活动库存小于等于 0。

### 12.7 订单 PDF 下载失败

检查：

1. 是否保存了订单所属店铺的 Ozon 后台 Cookie。
2. Cookie 是否过期。
3. 订单号或货件编号是否正确。
4. 是否选择了输出目录。
5. Ozon 后台是否需要重新登录。

### 12.8 百度网盘素材下载失败

检查：

1. 是否填写百度网盘 Cookie。
2. Cookie 中是否包含有效 BDUSS。
3. 搜索目录是否正确。
4. 是否需要开启递归搜索。

### 12.9 AI 图片或文案失败

检查：

1. API Key 是否保存。
2. 接口地址是否正确。
3. 模型名称是否正确。
4. Prompt 是否为空。
5. 是否超过接口额度或限流。

## 13. 安全和操作建议

- 批量更新库存、价格和活动前，先用少量商品验证流程。
- 删除活动商品前，确认当前选中的活动 ID 和活动名称。
- 处理全类目商品前，确认类目、类型和店铺无误。
- 新店铺首次使用时，先测试 Ozon 连接，再查询仓库。
- 定期检查任务记录，失败任务不要只看结果文件，也要看日志。
- 多店铺操作时，注意 Cookie 和店铺是一一对应的。
- 不要把 Api-Key、OSS Secret、Cookie 发给无关人员。

## 14. 推荐日常工作流

新品上架：

1. 设置店铺、OSS、默认目录。
2. 素材生成中转 3:4 图片。
3. 上架运维中读取或选择商品模板。
4. 发布新品前执行预检查。
5. 提交上架任务。
6. 到任务记录看结果。
7. 在库存价格活动中查询仓库、补库存、改价或申报活动。

订单处理：

1. 订单查询中选择日期和店铺。
2. 查询订单并勾选。
3. 保存对应店铺 Cookie。
4. 选择输出目录。
5. 下载勾选订单。
6. 到任务记录打开结果目录。

商品维护：

1. 库存价格活动中查询商品。
2. 对当前列表或全类目执行库存、价格、条码操作。
3. 浏览量与合并中查询高浏览商品。
4. 勾选符合条件的同类目商品并合并商品卡。
5. 需要改标题、图片或富内容时使用“更新商品”。
