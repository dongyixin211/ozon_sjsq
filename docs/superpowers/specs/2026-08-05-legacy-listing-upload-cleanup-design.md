# 旧批量上架素材安全清理设计

## 目标

释放旧版批量上架直传素材占用的云图库容量，同时不删除仍在上传、近期使用或未完成授权的对象。

## 规则

- 默认保留已完成上传记录 7 天。
- 未完成且未过期的上传授权永远不清理。
- 已完成记录在保留期内不清理。
- 清理前再次确认对象仍属于用户的 `legacy-listing/<userId>/` 前缀。
- 数据库记录删除与 OSS 对象删除分别记录结果；单个对象失败不影响其他对象处理。
- 默认 dry-run，只有明确设置删除开关时才实际删除。

## 实现

- 增加清理审计表，记录用户、对象、大小、原因、执行时间和结果。
- 增加独立脚本 `npm run listing:uploads:cleanup`，支持 `--status` 和 `--delete`。
- 清理查询排除存在未完成授权的同名对象，并限制单次批量数量。
- 只有 OSS 删除成功后才删除容量统计记录；删除失败保留记录，下一次可重试。
- 过期授权记录单独清理数据库记录，不删除已完成且仍在保留期内的对象。

## 验证

- 单元测试覆盖 7 天边界、未完成授权保护、用户前缀保护和 dry-run 行为。
- 服务端类型检查、全量测试和构建通过后，再在生产执行一次 status，再执行 delete。
