# 订单下载文件夹命名设计

## 目标

将项目内所有订单下载产生的订单子目录，从仅使用订单号或货件编号，统一改为：

`店铺名称+货号1、货号2+订单编号`

## 规则

- 店铺名称读取本地店铺配置；本地历史订单中的店铺名称可作为面单直下命令的补充数据。
- 货号读取 Ozon 返回的订单商品 `offer_id`；多个货号去重后使用中文顿号 `、` 连接。
- 第三个字段沿用当前任务输入的订单号或货件编号，不改变现有订单查询逻辑。
- 店铺名称、货号和订单编号分别替换 Windows 文件名非法字符。
- 无法取得货号时使用 `未知货号`，保证目录始终包含三个字段。
- 目录命名在 Rust 后端集中实现，覆盖订单列表批量下载、订单页手动下载、旧版订单下载页和物流面单直下命令。

## 实现

- 新增纯函数生成安全目录名，覆盖单货号、多货号去重、非法字符和缺失货号测试。
- 完整订单下载先解析 Ozon 货件与商品，再创建目标目录并写入文件。
- 物流面单直下命令从数据库读取店铺和已保存订单货号，再使用相同纯函数创建目录。
- 不修改下载文件自身名称，不修改订单接口、任务状态或数据库结构。

## 成功标准

- 所有订单下载目录符合 `店铺名称+货号+订单编号`。
- 多货号稳定去重并使用 `、` 连接。
- Windows 非法字符不会导致目录创建失败。
- Rust 单元测试、前端相关测试和项目构建通过；无关基线失败需明确报告。
