# 勾选订单物流 PDF 下载设计

## 目标

“下载勾选”继续下载每个勾选货件原有的 Ozon 文件，并额外下载与该货件一一对应的物流 PDF。物流 PDF 链接不得作为 `postingNumber` 或订单编号传给 Ozon 接口。

## 数据映射

- 勾选 N 个货件时，要求输入 N 个非空且不重复的物流 PDF 链接。
- 按订单表中的勾选顺序生成货件编号列表。
- 第 N 个货件编号与第 N 个物流链接组成固定配对。
- Ozon 查询只使用货件编号；物流 PDF 使用对应 URL 直接通过 HTTP 下载。

## 下载流程

对每个勾选货件依次执行：

1. 使用 `postingNumber` 查询 Ozon 货件信息。
2. 下载现有的 Ozon 条形码、拣货单、标签及启用的货号素材。
3. 使用该货件对应的物流 URL 下载 PDF。
4. 将物流文件保存到同一货件目录，文件名为 `logistics-label.pdf`。

## 防错规则

- 前端从已加载订单行中重新解析勾选货件，避免链接文本进入货件编号数组。
- 前端在提交前校验勾选数量与物流链接数量一致，并禁止链接重复。
- 后端拒绝 HTTP/HTTPS URL 形式的订单或货件编号，避免错误请求 Ozon。
- 后端继续校验每个订单只对应一个有效 HTTP/HTTPS PDF 链接。

## 测试范围

- 验证勾选货件与物流链接按顺序正确配对。
- 验证生成的 `orderNumbers` 仅包含勾选行的 `postingNumber`。
- 验证物流 URL 不会进入 Ozon 查询编号。
- 验证数量不一致、重复链接和 URL 形式货件编号会被拒绝。

## 不在范围内

- 不改变“开始下载”的手工订单输入行为。
- 不改变原有 Ozon 文件种类、文件名或素材下载设置。
- 不增加新的配置项或并发下载机制。
