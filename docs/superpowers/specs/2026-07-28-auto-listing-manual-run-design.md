# 自动上品手动执行与进度入口设计

## 目标

在“自动上品方案”卡片上提供明确的单次执行和进度查看入口，让用户无需修改执行时段即可立即运行指定方案，并能快速进入批次任务中心查看执行状态。

## 交互设计

- 每个方案卡片增加“立即执行一次”按钮。
- 点击后调用本地助手已有的 `run_auto_listing_plan_now` 命令，并只执行当前方案。
- 手动执行忽略方案配置的执行时段，但仍要求方案已启用、本地助手已连接、店铺配置有效，并遵守 Ozon 实时额度与图片唯一分配规则。
- 执行请求期间按钮显示“启动中…”并禁用，避免重复点击。
- 启动成功后显示结果提示，并跳转到“素材 → 上传中”。
- 每个方案卡片增加“查看进度”按钮，直接跳转到“素材 → 上传中”。

## 自动调度注册

- 浏览器工作台检测到兼容的本地助手并取得云端登录信息后，自动注册当前账号的调度会话。
- 自动注册只按方案配置的执行时段运行，不得像“立即执行一次”一样忽略时段。
- 本地助手定时轮询继续负责后续执行，即使用户离开“自动上品方案”页面也不受影响。
- 客户端需要区分“按时段调度”和“强制执行”，因此随本功能发布兼容版本更新。

## 进度与记录

- “素材 → 上传中”的批次任务中心作为自动上品主进度入口，展示等待、准备中、提交中、完成、失败及图片明细。
- “任务/设置 → 任务记录”继续展示本地套图、标题生成和商品提交任务记录。
- 本次不新增重复的独立记录页面。

## 错误处理

- 本地助手未连接时禁止执行，并提示先启动本地助手。
- 云端登录状态缺失、方案不可用或接口失败时展示现有错误信息，不创建假任务。
- 同一方案启动请求进行中时不允许再次触发。

## 成功标准

- 用户能在方案卡片点击“立即执行一次”，无需处于自动执行时段。
- 调用参数包含当前账号、云端地址、登录令牌和当前方案 ID。
- 成功后进入“上传中”页面查看进度。
- “查看进度”不触发任务，只负责跳转。
- 现有方案新建、编辑和自动调度行为保持不变。
- 本地助手连接后会自动注册调度会话，进入执行时段后不需要先手动运行一次。
