# 云后端管理员后台

云后端现在内置一个轻量管理员页面：

```text
http://127.0.0.1:8787/admin
https://api.你的域名.com/admin
```

## 登录方式

第一版使用服务器 `.env` 里的：

```env
ADMIN_TOKEN=...
```

打开 `/admin` 后，把 `ADMIN_TOKEN` 填入页面并保存到本浏览器。

## 当前功能

- 生成授权密钥
  - 月卡 99
  - 季卡 249
  - 年卡 899
- 查看最近 200 个用户
- 查看会员套餐和到期时间
- 查看设备名和最后在线时间
- 解绑用户设备

## 安全提醒

管理员后台只适合自己使用，不建议公开给普通用户。

正式上线后建议：

- 后台路径加 Nginx IP 白名单
- `ADMIN_TOKEN` 使用强随机字符串
- 不要把 `ADMIN_TOKEN` 发给客户
- 后续再升级为真正管理员账号登录
