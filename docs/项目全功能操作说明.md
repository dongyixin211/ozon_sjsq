# Ozon SJSQ 项目全功能操作说明

> 本文档以当前项目实现为准，面向 Ozon 店铺运营人员、云端工作区用户和管理员。它说明每项功能的用途、前置条件、操作方法、后台处理结果及常见失败处理。涉及密钥、Cookie 和授权码时，只填写到软件界面中，禁止在聊天记录、Excel、截图或公共文档中泄露。

## 1. 项目用途与功能边界

Ozon SJSQ 是一套面向 Ozon Seller 运营的本地工作台，同时可连接云端工作区。它覆盖以下完整业务链路：

1. 准备和处理商品图片、标题、文件名与场景/样机套图。
2. 配置一个或多个 Ozon 店铺、对象存储和 AI 服务。
3. 根据 Excel、商品模板和 SKU 图片目录批量发布新品。
4. 在上架成功后自动生成条码、补库存和申报促销活动。
5. 更新已上架商品、管理库存与价格、处理活动、查看浏览量和合并商品卡。
6. 查询订单、下载标签/条码/拣货文件，并可按货号检索素材。
7. 通过云图库、云端套图和自动上架方案持续处理商品。
8. 通过任务记录、日志、诊断、许可证和管理员控制台维护运行状态。

### 1.1 角色说明

| 角色 | 主要功能 |
| --- | --- |
| 店铺运营人员 | 素材、商品发布、商品维护、订单、任务记录。 |
| 云端工作区用户 | 图库上传、云端样机套图、自动上架方案与任务中心。 |
| 店铺管理员 | 配置 API、对象存储、AI 服务、店铺关系、默认目录和许可证。 |
| 云服务管理员 | 管理云端账号、授权、资源、任务与服务运维；技术细节请参阅已有云端运维文档。 |

### 1.2 数据保存位置与安全原则

- 店铺配置、常用目录、模板和任务记录由本机应用维护；敏感信息通过系统密钥存储机制保存。
- Ozon `Api-Key`、对象存储密钥、Ozon 后台 Cookie、百度网盘 Cookie 和云端登录凭证均属于敏感数据。
- 业务 Excel 可保存货号、标题、简介、富文本和价格等商品资料，但不得保存任何密钥或 Cookie。
- 发布、更新、库存、价格、活动、合并卡片均可能直接影响线上店铺。首次使用请先用少量商品验证。

## 2. 首次配置

完成以下配置后再进行素材、上架或订单操作。

### 2.1 云服务与许可证

**用途：** 启用云图库、自动上架和云端账号相关功能。

**操作：**

1. 打开“任务/设置 → 兑换密钥”。
2. 如尚未拥有云端账号，切换到“注册”，填写手机号、密码与注册授权密钥后注册。
3. 已有账号时切换到“登录”，填写手机号和密码。
4. 在“设置 → 云服务”填写云后端 API 地址并保存。
5. 登录成功后，进入素材工作区的图库页面；应用会检查并同步当前启用的本地店铺到云端。

**完成标志：** 页面不再显示“请先登录云端账号”，并可以浏览云图库、创建自动上架方案。

**异常处理：**

- 无法登录：确认云后端 API 地址、网络、手机号/密码和授权状态。
- 云端店铺未出现：在云服务页面点击“重新同步”，并确认本地店铺处于启用状态。
- 不再使用当前账号：在“兑换密钥”页面点击“退出登录”。

### 2.2 新增和维护店铺

**入口：** “设置 → 店铺与 API Key”，也可以从“上架 → 店铺管理”新增或编辑店铺。

**填写项：**

- 店铺名称：用于页面识别和任务记录。
- `Client-Id` 与 `Api-Key`：Ozon Seller API 所需凭证。
- 店铺类型：主店或跟卖店铺。
- 跟卖主店、跟卖唯一仓库 ID：仅跟卖场景需要。
- 店铺水印图片：可作为图片处理的默认水印来源。
- 启用状态：停用店铺后不应作为日常操作和同步目标。

**操作步骤：**

1. 点击“新增店铺”或“编辑”。
2. 填写店铺名称、`Client-Id`、`Api-Key` 和店铺类型。
3. 点击“保存店铺”。
4. 在已保存店铺列表中点击连接测试，确认可以访问 Ozon。
5. 如店铺不再使用，在确认不影响历史任务后点击“删除”。

**完成标志：** 测试连接显示成功响应；店铺可在商品、订单和库存页面的店铺选择器中选到。

### 2.3 对象存储（OSS）配置

**用途：** 批量上架或更新图片时，将本地图片上传为 Ozon 可访问的公网 URL。

**入口：** “设置 → OSS 上传”。

**需要准备：** `AccessKeyId`、`Secret`、Bucket、Endpoint 和图片公网域名。默认值仅是示例或历史默认配置，应以实际桶和域名为准。

**操作步骤：**

1. 选择目标店铺。
2. 填写对象存储的 AccessKeyId、Secret、Bucket、Endpoint 和 Public Domain。
3. 保存店铺配置。
4. 点击 OSS 测试上传。

**完成标志：** 页面返回可访问的测试上传 URL。

**异常处理：** 检查访问密钥权限、Bucket 名称、地域 Endpoint、公共读/签名策略和公网域名配置；确认企业网络未阻断对象存储。

### 2.4 AI Provider 与默认目录

**AI Provider 用途：** 为“GPT 图片生成”和“AI 生成标题”提供兼容 OpenAI 协议的接口、模型和提示词。

**默认目录用途：** 提供源图片、输出图片、水印、标题输出和上架 Excel 的默认路径，减少重复选择。

**操作要点：**

1. 在设置中保存 AI 接口地址、模型及其 API Key；在对应素材页面可刷新可用模型。
2. 设置默认源目录、默认输出目录、水印图片、文案输出目录、上架 Excel 模板和上架最大条目数。
3. 路径应使用本机稳定目录，避免使用会自动清理的临时目录或网络盘断连路径。

## 3. 页面导航与首页

应用按“首页、素材、上架、订单、任务/设置”组织。

| 工作区 | 主要页面 |
| --- | --- |
| 首页 | 店铺运营总览、店铺健康矩阵、配额视图。 |
| 素材 | 转 3:4 + 水印、GPT 图片生成、AI 生成标题、图片重命名、云图库状态页。 |
| 上架 | 店铺管理、发布新品、已上架更新、库存价格活动、跟卖、订单文件下载、自动上架方案。 |
| 订单 | 订单查询与订单文件下载。 |
| 任务/设置 | 任务记录、运行日志、许可证/云端登录、店铺与系统设置。 |

首页用于快速判断店铺与任务是否健康，不替代具体业务操作。遇到失败任务时，优先进入“任务记录”查看失败原因和完整日志。

## 4. 素材处理

### 4.1 转 3:4 + 水印

**用途：** 把源图片批量处理为适合商品主图使用的 3:4 图片，并添加可选水印。

**前置条件：** 有可读取的源目录和可写入的输出目录；如要添加水印，准备 PNG/JPG 水印文件。

**操作步骤：**

1. 进入“素材 → 转 3:4 水印”。
2. 选择源目录和输出目录。
3. 选择水印图片；不需要水印时保持为空。
4. 设置“数量上限”，`0` 表示不限制。
5. 先点击“预检查”，阅读目录、图片和配置检查结果。
6. 预检查无阻断问题后点击“开始生成”。
7. 到“任务记录”查看数量、日志和失败文件。

**结果：** 输出目录生成处理后的图片；任务状态记录每批处理结果。

**常见失败：**

- 源目录为空或不可读：重新选择本机目录并确认文件权限。
- 输出目录不可写：更换目录或检查权限。
- 水印显示异常：使用透明背景 PNG，避免超大分辨率或损坏文件。

### 4.2 GPT 图片生成

**用途：** 以每个 SKU 文件夹中的第一张原图为参考，调用 AI 生成适合 Ozon 的竖版商品图。

**前置条件：** 已配置 AI Provider；上传图片目录按 SKU 分文件夹；选择可用图片模型。

**操作步骤：**

1. 进入“素材 → GPT 图片生成”。
2. 选择上传图片目录。
3. 选择 AI 接口与 AI 模型；必要时点击“刷新模型”。
4. 编辑图片 Prompt。默认 Prompt 要求保持商品主体、图案、颜色和材质一致，生成干净的 3:4 商品图。
5. 先点击“预检查”。
6. 点击“开始生成”。
7. 到任务记录查看每个 SKU 的生成状态；生成图应人工抽检后再进入上架素材目录。

**限制：** AI 图可能与原图存在颜色、文字、细节偏差。对于 SKU、价格、尺寸、品牌标识等关键内容，必须人工检查，不可完全依赖自动生成。

### 4.3 AI 生成标题

**用途：** 读取 SKU 和文件名信息，生成适合 Ozon 的商品标题。

**操作步骤：**

1. 进入“素材 → AI 生成标题”。
2. 选择上传图片目录和标题输出目录。
3. 选择文本模型，必要时刷新模型列表。
4. 编辑标题 Prompt。可使用货号和图片名等上下文变量。
5. 点击“预检查”，确认源图目录、输出目录和 AI 配置均正常。
6. 点击“开始生成”。
7. 打开标题输出目录复核标题，再写入上架 Excel。

**注意：** 标题应符合 Ozon 平台规则；AI 结果需要人工审阅，尤其是材质、规格、品牌和禁限词。

### 4.4 图片重命名

**用途：** 将文件按文件名排序复制到新目录，生成“前缀 + 001”这类连续编号文件名。

**操作步骤：**

1. 进入“素材 → 图片重命名”。
2. 选择原素材文件夹和生成后存放目录。
3. 填写前缀，页面会展示命名示例。
4. 点击“开始重命名”。
5. 在输出目录核对文件数量、排序和文件扩展名。

**说明：** 功能以复制/生成结果为目标。不要在未备份的情况下直接手动覆盖原始素材。

## 5. 场景图与套图

### 5.1 本地场景图合成

**用途：** 按固定场景模板，把商品原图批量合成为电商展示图。当前可选场景包括平铺全幅、头巾侧戴、头巾后戴、折叠系结和尺码图等。

**前置条件：**

- 源图片目录、输出目录和模板目录可读取/写入。
- 模板目录需按场景 ID 放置底图或资源，例如 `flat_full.jpg`、`flat_full.png` 或 `flat_full/base.jpg`。
- 如需试运行，可指定单张图片；批量运行则使用源目录。

**操作步骤：**

1. 打开“本地场景图合成”入口（部分版本不在主导航中，但功能可由本地场景任务调用）。
2. 选择源目录、输出目录和模板目录。
3. 可选：选择单张图片进行模板测试。
4. 设置输出比例：1:1、3:4、4:3 或 16:9。
5. 可选：填写尺寸标注。
6. 设置最大处理数量，`0` 表示不限制。
7. 勾选需要生成的场景模板。
8. 点击“开始生成”，随后在任务记录查看状态。
9. 打开输出目录，抽检每个 SKU 的场景图位置、边缘、尺寸文字和颜色。

### 5.2 云图库样机套图

**用途：** 将云图库中的原始商品素材套入可用样机模板，生成多张独立的云端套图结果，可继续用于人工筛选或自动上架。

**操作步骤：**

1. 先登录云端账号，并在图库上传原始商品图片。
2. 在图库中筛选或选择待处理素材；建议先确认货号、商品类型和图片比例。
3. 在“当前套图样机/选择套图样机”选择模板。
4. 发起套图任务并查看任务状态。
5. 渲染完成后，在图库中查看生成图片、缩略图、模板名称和套图状态。
6. 审核合格的套图；需要重新制作时应修改原始素材或更换模板，而不是把已经生成的套图继续当作原图重复套图。

### 5.3 套图的技术实现原理

套图是**模板图像合成**，不是 AI 重新生成商品图。其处理逻辑如下：

1. **模板定义：** 每个样机模板使用 JSON 描述一个或多个场景。每个场景定义画布尺寸、输出格式和图层顺序。
2. **商品图替换：** 商品原图会被裁切、缩放和定位到模板规定的替换区域。
3. **贴合处理：** 简单模板使用普通缩放与位置变换；复杂模板可使用透视变换、透视网格或 UV 映射，使图案贴合围巾、服装或其他样机表面。
4. **边缘与材质：** 蒙版、裁剪蒙版、羽化和颜色校正控制商品图可见区域；阴影、高光、褶皱和纹理图层按顺序叠加。
5. **混合效果：** 模板可使用 `multiply`、`screen`、`overlay`、`darken`、`lighten`、`linear_light` 等混合模式，模拟真实光照和材质。
6. **多场景输出：** 同一模板可以输出多张不同场景的成图；结果以独立素材记录保存到云图库。

**运行方式：**

- 浏览器侧可以使用 HTML Canvas 在本机渲染模板，然后把结果图片上传到云端。
- 云端服务可以使用 `sharp` 图像处理库执行同类图层、蒙版和混合合成。
- 本地助手还提供 Rust `image` 图像库实现，用于本地渲染能力。

因此，套图质量主要取决于**原始商品图、样机模板、蒙版/UV 资源和人工审核**，而不是提示词。AI 图片生成功能与套图功能相互独立。

## 6. 商品上架：从准备到验收的完整流程

本节是新品发布的标准闭环。建议首次只选择 1～3 个 SKU 验证模板、图片和对象存储，再扩大批量。

### 6.1 第一步：准备店铺与服务

在提交上架前确认：

- 目标店铺已启用，Ozon 连接测试成功。
- 图片上架需要对象存储时，OSS 测试上传成功。
- 已选择正确的商品模板；新类目优先从一件成功的线上商品读取模板。
- 如需上架后自动处理，已可查询仓库和活动。

### 6.2 第二步：准备 Excel 和图片目录

**Excel 至少应提供：** 货号、标题、简介、JSON 富文本内容；具体可用字段以当前上架表单和模板为准。

**图片目录规范：** 使用“3:4 图片目录/货号”匹配。例如货号为 `SKU-1001`，对应图片应位于 `图片根目录/SKU-1001/`。图片目录与 Excel 货号不匹配是最常见的阻断原因。

**建议：**

- 文件夹名称与 Excel 货号完全一致，避免空格、全角半角混用和不可见字符。
- 上架前人工确认首图、图片比例、套图是否合格。
- 视频链接可按行填写；没有视频时不要填无效链接。

### 6.3 第三步：准备商品模板

**用途：** 商品模板决定类目、商品类型、属性和尺寸结构，发布新品和更新商品均可使用。

**操作：**

1. 在商品模板区域选择本地已保存模板；或输入一件线上成功商品的货号后点击“读取线上模板”。
2. 核对类目、类型、必填属性、尺寸与仓库相关配置。
3. 点击“保存模板”以便下次复用。
4. 如已从外部得到正确 JSON，可使用“应用粘贴 JSON”；确认后保存。
5. 无用模板可删除，但不要删除仍被自动上架方案引用的模板。

**规则：** 不同类目或不同商品类型不要共用同一模板；模板正确不代表 Excel 数据正确，两者都必须核对。

### 6.4 第四步：创建发布任务

**入口：** “上架 → 店铺管理 → 功能中心 → 发布新品/批量上架”。

**操作步骤：**

1. 选择目标店铺。
2. 选择“3:4 图片目录”和“Excel 路径”。
3. 设置最大条目数量；先以小数量试跑。
4. 如需要，填写视频链接，每行一个。
5. 选择或读取商品模板。
6. 如需自动后处理，按下一节配置仓库、库存与活动。
7. 点击“预检查”。预检查发现货号无图片、目录不可读、模板缺失或配置缺失时，先修复再继续。
8. 点击“提交上架任务”。
9. 打开“任务记录”查看任务进度、日志和逐项结果。

### 6.5 系统如何处理上架任务

提交后，系统按批次完成下列处理：

1. 读取 Excel 中的商品数据。
2. 按货号匹配 SKU 图片目录。
3. 将需要上传的图片发送到对象存储，获得公网 URL。
4. 用商品模板、Excel 数据、图片 URL 和可选视频构建 Ozon 导入项目。
5. 调用 Ozon 商品导入接口提交任务。
6. 记录 Ozon 任务 ID、本地任务日志和单个 SKU 的处理结果。
7. 在图片目录或结果位置生成 `batch_upload_results.xlsx`，保存货号、标题、图片数、状态、SKU、任务 ID、对象存储文件夹和错误信息等结果。

### 6.6 第五步：上架后自动处理

**用途：** 在上架成功并拿到 Ozon 商品 ID 后，自动执行条码、库存和促销活动操作。

**配置步骤：**

1. 在发布页面勾选“上架后自动处理”。
2. 点击“查询仓库”，选择补库存仓库。
3. 填写自动库存数量。
4. 点击“刷新活动”，选择目标促销活动。
5. 填写统一活动价；留空时，系统优先使用活动候选商品返回的建议价。
6. 填写活动库存。
7. 返回发布表单并提交上架任务。

**处理顺序：** 导入成功 → 等待商品 ID → 生成条码 → 更新库存 → 加入活动。单个商品在自动处理环节失败，不应中断其他商品的导入；失败信息会写入任务日志和结果表。

### 6.7 第六步：验收与失败恢复

**必须核对：**

- 任务记录是否完成，是否存在失败 SKU。
- `batch_upload_results.xlsx` 中货号、图片数、SKU、Ozon 任务 ID 和错误信息是否符合预期。
- Ozon Seller 后台是否出现商品；图片、标题、类目、属性、库存、条码和活动是否正确。
- 商品未成功时，先按错误类别补齐图片、Excel 字段、模板、OSS 权限、仓库或活动设置，再只重新提交需要恢复的条目。

**不要直接重复整批上架：** 在不清楚首次结果时全量重跑，可能造成重复商品或重复任务。先以任务 ID 和结果 Excel 判断失败范围。

## 7. 已上架商品运营与维护

### 7.1 更新商品

**用途：** 按货号对已上架商品更新标题、简介、图片、视频和 JSON 富内容。

**操作步骤：**

1. 打开“已上架更新”。
2. 选择 3:4 图片目录、Excel 和最大条目数量。
3. 勾选本次允许更新的字段：标题、简介、图片、视频、JSON 富内容。
4. 选择或读取商品模板；需要保持原有结构时尤其重要。
5. 点击“预检查”。
6. 确认后点击“提交更新任务”。
7. 在任务记录中查看结果。

**规则：** 未勾选的字段不会主动更新；更新图片会重新上传对象存储；不更新图片时保持线上图片 URL。页面还提供“只更新视频”及按类目批量更新视频链接的操作，视频链接应一行一个并先在小范围验证。

### 7.2 库存、价格和条码

**入口：** “库存价格活动 → 商品列表”。

**操作步骤：**

1. 点击“加载分类”，用类目搜索选择目标分类。
2. 设置返回数量上限，点击“查询商品”；也可直接拉取零库存或无条码商品。
3. 点击“查询仓库”，选择补库存仓库并填写库存数量。
4. 如要改价，填写新售价、可选划线价和备用币种。
5. 对当前勾选列表，可点击“更新列表库存”“更新列表价格”或“生成条码”。
6. 对所选类目全部商品，可点击“更新类目库存”“更新类目价格”或“同时更新”。
7. 查看页面的提交中/成功/失败反馈和任务记录。

**重要区别：** “所选类目全部商品”会扫描整个类目，不受当前返回数量上限限制；影响范围较大，操作前需再次确认店铺、仓库和价格。

### 7.3 促销活动申报

**入口：** “库存价格活动 → 活动申报”。

**操作步骤：**

1. 点击“查询活动”并选择目标活动。
2. 点击“查询可参加商品”。
3. 在可参加商品列表中勾选商品。
4. 填写统一活动价和活动库存。
5. 点击“新增参加活动”。
6. 要移除商品时，查询已参加商品，勾选后点击“删除参加活动”。
7. 要清空活动时点击“删除当前活动所有商品”，并完成页面要求的二次确认。

**注意：** 新增活动只能使用“可参加商品”列表的选择项，普通商品表勾选不会自动用于活动申报；清空操作会分页处理当前活动的全部商品，而不仅是当前页。

### 7.4 浏览量与合并商品卡

**用途：** 按商品详情页浏览量筛选商品，并把条件相同的商品合并为商品卡。

**操作步骤：**

1. 进入“浏览量与合并”。
2. 选择统计日期并设置最低详情页浏览量。
3. 点击“查询浏览量”。
4. 勾选需要合并的商品。
5. 点击“合并所选商品”，页面进入确认状态后再次确认执行。

**合并规则：** 只处理勾选商品；严格按“类目 + 类型”分组；每组最多 20 个；不足 2 个、缺少类目/类型或缺少型号属性的商品会跳过。合并只处理型号/合并属性，不改变标题、图片、价格和库存。

### 7.5 跟卖同步与自动化

**用途：** 将主店商品同步到跟卖店，并按倍率调整价格。

**配置：**

1. 在设置中把源店配置为主店。
2. 新增跟卖店，店铺类型选择跟卖店铺，并指定跟卖主店。
3. 跟卖店有多个仓库时，填写唯一仓库 ID。

**手动同步：** 打开“跟卖商品同步”，确认主店和跟卖店列表，设置加价倍率，点击“开始同步”，再到任务记录查看逐商品结果。

**自动化：** 在“跟卖自动化”中配置执行间隔、自动跟卖上架总上限、加价倍率、自动库存、自动条码和自动活动等选项，点击“启动自动化”。停止时使用“暂停/停止”控制或在任务记录取消运行任务。

### 7.6 定时运维与接口诊断

- “定时运维”可按店铺或全部店铺启动、暂停和停止周期性维护任务；先保存配置和执行间隔。
- “接口诊断”中的“测试 Ozon”用于验证当前店铺 API 连接和查看接口结果。
- 诊断失败时先检查 `Client-Id`、`Api-Key`、店铺启用状态、网络和 Ozon 平台权限，不要通过反复重试掩盖配置错误。

## 8. 订单查询与订单文件下载

### 8.1 订单历史查询

**入口：** “订单 → 订单查询”。

**操作步骤：**

1. 设置同步开始日期、结束日期、订单状态、关键词和最多显示数量。
2. 执行查询，系统按当前配置拉取可见订单。
3. 在订单列表中筛选、翻页、全选或勾选所需订单。
4. 需要进入下载流程时，使用“下载勾选”或将订单号写入上架工作区的订单输入框。

### 8.2 下载勾选订单文件

**用途：** 下载订单面单、条码 PDF、拣货单等文件。

**操作步骤：**

1. 在订单列表勾选订单。
2. 打开下载与 Cookie 设置，选择输出目录。
3. 保存当前店铺的 Ozon 后台 Cookie；也可提供 Ozon 后台 HAR 或粘贴 Cookie。
4. 点击下载；若系统要求物流贴单 PDF 地址，逐项填写并点击“确认并下载”。
5. 到任务记录查看下载状态和日志。

**结果：** 每个订单或货件编号创建独立文件夹，通常包含 Ozon 标签、条码 PDF 和拣货单 PDF。

### 8.3 手动下载订单文件与货号素材

**入口：** 上架工作区的“订单文件下载”，或订单页的“手动下载订单文件”。

**操作步骤：**

1. 输入订单号或货件编号；可一行一个，也可用空格或逗号分隔。
2. 选择输出目录。
3. 提供 Ozon 后台 HAR 或 Cookie，并保存当前店铺 Cookie。
4. 如需货号素材，启用素材下载，填写百度网盘 Cookie 和网盘搜索目录。
5. 点击“开始下载/手动下载订单文件”。
6. 在任务记录查看日志；失败时读取具体订单的失败原因。

**常见失败：**

- PDF 无法下载：Cookie 失效、HAR 不完整、订单号/货件号不正确或后台权限不足。
- 百度网盘素材未找到：Cookie 失效、搜索根目录错误、货号命名不一致或文件不存在。
- 输出目录无文件：检查任务日志、文件权限和杀毒软件拦截。

## 9. 云图库与自动上架

### 9.1 云图库素材管理

**用途：** 将本地商品图片纳入云端素材库，供套图、人工审核和自动上架使用。

**常用功能：**

- 批量上传图片或选择整个文件夹。
- 按货号关键字、商品类型、图片比例、套图状态和已使用货号筛选。
- 查看素材详情、缩略图和上传/套图进度。`n- 对本页或已选素材执行单张/批量套图、覆盖重新生成，必要时删除不再使用的素材（删除前需要再次确认）。
- 查看待上传、上传中、已上传和精品图库等状态页。
- 查看后台上传任务、上传记录、日志，并取消可取消的任务。

**操作建议：** 先保证文件名或目录能稳定关联货号；批量上传后先在“上传记录”核对数量与失败项，再进行套图或自动上架。

### 9.1.1 已上传商品图片的重新套图与修复

**适用场景：** 已经记录为店铺上架图片的素材需要更换样机效果，或需要重新同步可用套图到 Ozon 商品图片。

**操作步骤：**

1. 切换到“已上传图片”，按店铺或货号筛选目标素材。
2. 选择当前样机模板；先确认模板和原始图片适合该商品。
3. 勾选需要处理的图片，使用“重新生成所选商品的当前样机套图，并更新 Ozon 商品图片”操作。
4. 系统先生成新套图，再同步新套图记录，最后提交 Ozon 商品图片更新；过程中在页面进度区或任务记录查看状态。
5. 若页面提供图片链接修复操作，可针对当前本地店铺的已上传记录执行修复；它会扫描可处理记录并显示扫描、跳过、成功和失败数量。

**异常处理：** 新套图全部失败时，系统不会提交 Ozon 图片更新。应先检查模板资源、源图和样机选择；模板重新发布或源图修正后，再只重试失败项。

### 9.2 上架准备与店铺模板绑定

云端自动上架需要为每个目标店铺指定可用商品模板。

1. 在图库中打开“上架准备”。
2. 添加目标店铺；确认店铺已从本地同步到云端。
3. 为每个店铺选择商品模板，必要时选择本地 Ozon 模板作为来源。
4. 查看模板名称、类目说明和今日上架限额/剩余额度。
5. 点击“保存模板/保存上架设置”。

**限制：** 店铺没有可用模板、模板被删除、模板仓库信息缺失或超过日限额时，启用或执行自动上架方案会被阻止。修复配置后再运行。

### 9.3 自动上架方案

**用途：** 让系统按固定规则从图库选取合格素材、使用选定的样机和标题提示词，并按店铺配置发布商品。

**创建步骤：**

1. 进入“上架 → 自动上品方案”。
2. 点击“新建方案”。
3. 在向导中按顺序配置素材筛选条件、当前套图样机、标题提示词模板、目标店铺及每店商品模板。
4. 设置计划启用状态、每日配额、运行节奏或排程等页面提供的规则。
5. 查看“配置摘要”和“配置检查”，修复被标记的问题。
6. 保存方案。
7. 需要即时验证时，点击“立即执行一次”。

**执行流程：** 候选原始素材 →（需要时）样机套图 → 生成标题/上架数据 → 按店铺模板和限额创建上架任务 → 进入任务中心追踪。已生成套图结果不应被再次当作原始素材候选，以避免递归重复处理。

**一键准备：** 在图库准备区选择图片和店铺配置后，页面可一次执行“自动套图 → 生成标题 → 提交店铺上架”。这条流程仍会使用上架设置中的商品模板；库存、条码和活动由店铺的上架后自动运维配置处理。首次使用请只选择少量素材，并在任务中心确认每一步结果。

### 9.4 自动上架任务中心

**用途：** 监视自动上架的每个任务、图片分配和失败恢复。

**操作：**

- 查看上传中任务视图和任务进度。
- 暂停任务，在配置修复后继续。
- 对存在部分失败的任务点击“仅重试失败”。
- 展开图片明细，查看每个素材的分配状态。
- 对异常占用的素材使用“释放确认”，使其重新可被后续任务选择；释放前先确认原任务不会继续写入该素材。

## 10. 任务记录、日志与故障排查

### 10.1 任务记录

所有长时间或批量操作应通过“任务记录”核对：素材处理、上架、更新、订单下载、跟卖、云上传、自动上架和场景图等。

**操作：**

1. 打开“任务/设置 → 任务记录”。
2. 选择目标任务，查看状态、创建时间、结果摘要和日志。
3. 失败任务点击“失败原因”或“日志”。
4. 未完成且支持取消的任务可以点击“取消”。
5. 使用分页浏览历史任务和日志。

**处理原则：** 先读失败原因，再修复输入数据/配置，最后只重试失败范围；不要在未知状态下重复创建相同任务。


### 10.3 云端管理员控制台

管理员控制台用于管理云后端的账号、授权与资源，不是普通运营人员的日常工作区。管理员登录后应仅执行权限范围内的操作，并避免在控制台备注、导出或日志中保存明文密钥。

当前项目为管理员保留的能力包括：

- 查看和维护云端用户、许可证/授权状态及其生命周期。
- 查看云端图库、样机模板、自动上架相关资源和任务状态。
- 处理云端任务、配额和异常资源；当需要清理或解除占用时，先确认不会影响运行中的自动上架任务。
- 使用现有云端 API、管理员后台和部署运行手册进行服务级排障。

普通用户遇到云端账号、配额或模板不可用问题，应提供任务 ID、货号、操作时间和失败日志给管理员，而不是尝试绕过授权或直接修改服务端数据。

### 10.2 常见问题速查

| 问题 | 优先检查 |
| --- | --- |
| Ozon 连接测试失败 | `Client-Id`、`Api-Key`、店铺启用状态、网络与平台权限。 |
| 上架找不到图片 | Excel 货号与图片 SKU 文件夹名称是否完全一致；图片目录是否正确。 |
| OSS 上传失败 | 密钥权限、Bucket、Endpoint、公共域名与网络。 |
| 库存更新提示未选仓库 | 先查询仓库并选择目标仓库，再填写数量。 |
| 改价缺少币种 | 填写正确的新售价；必要时补充备用币种。 |
| 新增活动失败 | 从“可参加商品”列表选择商品，检查活动有效期、价格和库存。 |
| 订单 PDF 下载失败 | 更新 Ozon 后台 Cookie/HAR，检查订单号、后台权限和输出目录。 |
| 百度网盘素材失败 | 更新 BDUSS/Cookie，检查网盘搜索目录、货号与素材文件。 |
| AI 图片/标题失败 | 检查 AI 接口地址、模型、密钥、网络、Prompt 和输入目录。 |
| 套图失败或效果错误 | 检查源图、样机模板、场景资源、蒙版/UV 资源和图片比例；先用单张图片复现。 |
| 自动上架无法运行 | 检查云端登录、同步店铺、商品模板、库存仓库、素材状态和每日配额。 |

## 11. 推荐日常工作流

### 11.1 新品从素材到上架

1. 在设置中确认店铺、Ozon、OSS、AI 和默认目录。
2. 整理源图；需要时执行 3:4 + 水印、AI 生图、标题生成或重命名。
3. 上传云图库并完成样机套图，或使用本地场景图合成；人工筛选合格图片。
4. 准备 Excel，确保货号、标题、简介、富文本与图片目录对应。
5. 读取/选择正确商品模板。
6. 在发布新品中完成预检查，先小批量提交。
7. 在任务记录和 `batch_upload_results.xlsx` 验收。
8. 如启用自动后处理，核对条码、库存和活动。
9. 再扩大批量或创建云端自动上架方案。

### 11.2 日常店铺维护

1. 每日查看首页店铺健康和任务失败情况。
2. 查询订单并下载需要的文件。
3. 处理零库存、缺条码、价格或活动变更。
4. 按类目和浏览量评估商品，谨慎执行商品卡合并。
5. 跟卖店铺按配置同步，并查看同步任务结果。
6. 定期检查对象存储、AI Provider、Cookie 和许可证是否仍可用。
